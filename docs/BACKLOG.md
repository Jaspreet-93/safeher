# SafeHer — Product Backlog

**Document Version:** 1.0.0  
**Status:** Active  

This backlog captures out-of-scope items, future enhancements, and deferred ideas to prevent scope creep during active phases.

## Post-Phase Scope & Future Enhancements

| Item ID | Proposed Feature / Enhancement | Target Phase / Milestone | Notes & Prerequisites |
| :--- | :--- | :--- | :--- |
| **BLK-001** | Voice-Activated SOS (hotword detection) | Phase 10 (Mobile) | Requires on-device model to prevent unauthorized ambient listening; privacy evaluation mandatory. |
| **BLK-002** | Shake-to-Alert (hardware accelerometer) | Phase 10 (Mobile) | Native mobile only; requires calibration to avoid false alarms while running or dropping phone. |
| **BLK-003** | WhatsApp Business API Integration | Phase 3 (Post-SMS MVP) | Meta Business verification and message template pre-approval needed. |
| **BLK-004** | Wearable Bluetooth Panic Button Support | Post-v1.0 | Integration with hardware BLE beacons or smartwatches. |
| **BLK-005** | Municipal GIS Ingestion Pipeline | Phase 6 | Automated ingestion of city street light maintenance logs and CCTV locations. |
| **BLK-006** | Self-Hosted OpenStreetMap Tile Server | Phase 11 / Scale | TileServer-GL + Valhalla routing cluster for offline/high-scale caching. |
